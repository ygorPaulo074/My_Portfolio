# My Portfolio

Portfólio pessoal de **Paulo Ygor Oliveira Araújo**, graduando em Engenharia de Software. Página única em HTML, CSS e JavaScript puro (sem frameworks ou build step), com navegação por âncoras, revelação de seções por scroll e contato direto via WhatsApp e e-mail.

**Site:** https://ygorpaulo074.github.io/My_Portfolio/

## Estrutura

```
index.html      → conteúdo e marcação
style/main.css  → paleta, layout e animações
scripts/main.js → revelação de seções via IntersectionObserver
```

## Rodando localmente

Não há build — basta abrir `index.html` no navegador, ou servir a pasta:

```bash
python3 -m http.server 8000
```
